# Inbox: drop old single-file HTML lessons here

1. On github.com, open this folder and click **Add file → Upload files**.
2. Drag in your `.html` files and click **Commit changes**.

Files here are **not** on the website yet. The import step moves each one into the site and files it under a subject.
The repo is public, so check each file has no personal details (full name, school, photos, address) before uploading.
