Now switch it on with nobody in charge

Stop 03

Meet the one in charge

The missing piece is called the Operating System. It is not a new lump of hardware. There is no extra chip. It is a program — but a very unusual one.

It starts before everything else. It never stops running. And it holds the keys to every other part of the machine.

An operating system is the program that runs the other programs. It does none of your work. It decides who does work, when, and with what. Every job in the rest of this page is one of those decisions.

Stop 04

One rule changes everything

Here is the whole trick, and it is only one sentence long.

Programs are not allowed to touch the hardware. They have to ask.

Stop 05 · job one

Taking turns, faster than you can see

Your computer looks like it is doing five things at once. It is not. It is doing one thing, then another, then another — swapping so fast that your eyes give up.

Music, drawing and a clock are all running. Right now, at this exact instant, how many is one CPU working on?

That is exactly what it looks like

And that feeling is the illusion we are about to take apart. One pair of hands can only hold one recipe card. Slow the kitchen right down in the panel below and you will see it.

Correct — and it feels impossible

Exactly one. Everything else is frozen mid-instruction, waiting, without the faintest idea that it has been stopped. Slow it down below and watch.

Half right, in a clever way

Clicking a window does change who the Operating System favours — it gets longer turns. But it never changes the count. One CPU, one program, at any single instant.

The clever bit: how a program never notices

When the Operating System takes the turn back, it does something careful first. It writes down everything sitting in the CPU's tiny pockets — the registers — and exactly where the finger was pointing — the program counter. It puts that little note on a shelf.

Later, when it is that program's turn again, the OS puts every number back exactly where it was and points the finger at exactly the same instruction. The program carries on mid-sentence. It has no idea it was ever stopped, or that a million other things happened while it was away.

Lots of people think

“My computer does everything at the same time.”

What is really happening

It takes turns, thousands of times a second, and your eyes cannot keep up. Real CPUs do have a few cooks rather than one, so a handful of things truly do happen together — but your computer is running hundreds of programs with only a few cooks. Turn-taking is still what runs the whole show.

Connect it back

Where does this happen?
Right between your programs and the CPU. The Operating System is the only thing in the machine that is able to interrupt a running program.
What does it use?
The CPU, the registers and the program counter — the exact parts you already knew about. Now you know what they are really for.
What changed?
Crash 04 is gone. No program can freeze your computer for ever, because its turn was never given away. It was only ever lent.
Stop 06 · job two

Fences in the memory

RAM is one long row of numbered boxes, and every running program needs some of them. Nobody may simply help themselves.

So the Operating System does four things. It hands each program a region of its own. It builds a fence around it. It takes every box back the moment the program closes. And it never tells any program where the others are.

A program reaches over the fence into another program's boxes. What does the Operating System do?

It really is all one RAM — but no

The boxes are all in the same row, that part is true. But the Operating System checks every single reach before it is allowed to happen. Try the buttons below and watch what it does.

Lots of people think

“When a program crashes, the computer broke.”

What is really happening

A crash is usually the Operating System catching a program doing something it is not allowed to do, and stopping it before it can hurt anything else. The annoying message on your screen is actually the rescue working.

Connect it back

Where does this happen?
In RAM — that same long row of numbered boxes you already knew about. The Operating System stands guard over which program owns which numbers.
What does it use?
RAM addresses, and a little help from the CPU, which checks every reach as it happens.
What changed?
Crash 01 is gone. Two programs can never land in box 500 together, and one broken program can no longer take everything else down with it.
Stop 07 · job three

The map of the cupboard

Here is a surprise. Storage does not really contain folders, and it does not keep each file in one neat lump.

It contains an enormous number of tiny numbered places. One photo is very often chopped into pieces and scattered among them, wherever there happened to be room. So who on earth remembers where everything went?

Connect it back

Where does this happen?
Between storage and RAM — the journey you already knew a program has to make before it can run.
What does it use?
The cupboard, the workbench, and a map that lives nowhere else but with the Operating System.
What changed?
Programs stopped needing to know anything about disks. They ask for a name. They get given a thing.
Stop 08 · job four

Speaking every language

Remember crash 03 — the impossible homework? Every program having to know how to talk to every keyboard, screen and printer ever made?

This is how the Operating System makes that problem vanish. It learns all the languages, so that nobody else has to.

Connect it back

Where does this happen?
At the edges of the machine — every door in and every door out. Keyboard, mouse, screen, speaker, printer, network.
What does it use?
Devices, and a small helper the Operating System keeps for each one. You can think of it as a phrasebook for that exact model.
What changed?
Crash 03 is gone. A program can be tiny again. It says one simple sentence and the Operating System does the translating.
Stop 09 · job five

The referee

Everything inside a computer runs out. And every program wants all of it, right now.

Connect it back

Where does this happen?
Everywhere at once. This is not a separate job so much as the reason all the other four exist.

Stop 10 · the reveal

The secret about the one in charge

You have watched it hand out memory, take turns back, keep maps and speak a hundred languages. It is time to say what it actually is.

Where is the Operating System while the computer is switched off?

A very sensible guess — but no

There is no Operating System chip. Nothing about it is made of different stuff. It is a list of instructions, exactly the same kind of list as your favourite game.

Yes. It is a program, like any other

It sleeps in the cupboard with everything else. And like everything else, it has to be carried out to the workbench before it can do a single thing.

Nothing in a computer appears

Every single thing a computer runs has to come from somewhere, be copied to the workbench, and be read by the CPU. The Operating System is no exception at all.

Lots of people think

“The Operating System is the desktop, with the wallpaper and the icons.”

What is really happening

That picture is just one program that the Operating System runs, so that you have a way to talk to it. The real thing is invisible. It is working right now, thousands of times a second, while you look at the wallpaper.

It is not made of anything special. It simply went first — and it kept the keys. That is the whole difference. Not what it is, but when it starts and what it is allowed to do.
