Browser X-Ray

An exhibit about the web, for curious people aged 12+

See what really happens when you tap.

You press Play, Space, Log in or Add to cart a hundred times a day. Behind each tap, a team of hidden workers passes messages in a fraction of a second. This exhibit slows time right down so you can watch them. No coding needed.

Used in the example websites. It’s saved only in this browser. The Storage rooms mission shows how.
